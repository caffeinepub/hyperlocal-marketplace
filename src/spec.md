# Specification

## Summary
**Goal:** Simplify the shopkeeper login flow so approved shopkeepers can immediately access their dashboard without additional authentication steps or manual refreshes.

**Planned changes:**
- Remove unnecessary authentication barriers after admin approval
- Automatically update shopkeeper permissions in real-time when admin approves a shop
- Enable immediate dashboard access after approval without requiring logout/login
- Add automatic query invalidation to refresh shop status without page reload

**User-visible outcome:** After an admin approves their shop registration, shopkeepers can immediately access their dashboard and manage inventory, orders, and ledger without needing to log out, log back in, or manually refresh the page.
